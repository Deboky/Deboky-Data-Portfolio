# Deboky Saha — Data Analytics Portfolio

Welcome to my data analytics portfolio.

This repository contains some of the projects that I built to improve my skills in:
- Data Analytics
- SQL & PostgreSQL
- Python
- ETL Pipelines
- Power BI Dashboards
- Business & Operational Analytics

Most of the projects are based on real-world business scenarios and operational reporting style analytics.

As I am unable to share professional or organisational data due to privacy and confidentiality requirements, the projects in this portfolio are built using publicly available datasets while following practical business use cases.

I enjoy working on projects related to:

- ETL workflows
- government-style analytics
